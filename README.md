# سامانه ثبت نام پرسنل با SQLite

یک اپلیکیشن وب برای ثبت و مدیریت اطلاعات پرسنل با استفاده از پایگاه داده SQLite (نسخه WebAssembly برای مرورگر).

## ویژگی‌ها

- ✅ ثبت اطلاعات پرسنل (نام، نام خانوادگی، کد ملی، تلفن، آدرس، تاریخ تولد، سمت شغلی)
- ✅ افزودن عکس پرسنلی (آپلود و ذخیره در دیتابیس)
- ✅ ویرایش اطلاعات پرسنل
- ✅ حذف پرسنل
- ✅ جستجو در لیست پرسنل
- ✅ ذخیره‌سازی در SQLite (با sql.js)
- ✅ رابط کاربری فارسی و راست‌چین

## نحوه اجرا

### روش اول: استفاده از فایل BAT (ویندوز)

1. **اجرای سرور:** روی فایل `start.bat` دابل‌کلیک کنید
2. مرورگر به صورت خودکار باز می‌شود
3. آدرس: `http://localhost:4173`

### روش دوم: حالت توسعه

1. روی فایل `dev.bat` دابل‌کلیک کنید
2. آدرس: `http://localhost:5173`

### روش سوم: دستی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه نهایی
npm run build

# اجرای نسخه ساخته شده
npm run preview
```

## فایل‌های BAT

| فایل | توضیح |
|------|--------|
| `start.bat` | اجرای سرور نسخه نهایی (نیاز به build) |
| `dev.bat` | اجرای سرور توسعه (با Hot Reload) |
| `build.bat` | ساخت نسخه نهایی |

## تکنولوژی‌ها

- **React** - فریمورک رابط کاربری
- **Vite** - ابزار ساخت
- **Tailwind CSS** - استایل‌دهی
- **sql.js** - SQLite در مرورگر (WebAssembly)
- **Font Awesome** - آیکون‌ها

## ذخیره‌سازی اطلاعات

اطلاعات در LocalStorage مرورگر ذخیره می‌شود. دیتابیس SQLite به صورت Base64 در مرورگر نگهداری می‌شود.

> ⚠️ **توجه:** اطلاعات فقط در مرورگر فعلی ذخیره می‌شود. با پاک کردن داده‌های مرورگر، اطلاعات حذف خواهد شد.

## پیش‌نیازها

- Node.js نسخه 18 یا بالاتر
- مرورگر مدرن (Chrome, Firefox, Edge)
